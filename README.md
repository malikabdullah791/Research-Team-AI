# 🔬 AI Research Team

A multi-agent AI research assistant built with CrewAI and Streamlit.

## 🤖 AI Agents

### 1. Researcher
Collects and organizes research findings.

### 2. Analyst
Analyzes findings and identifies themes, insights and research gaps.

### 3. Writer
Creates a structured research report.

### 4. Reviewer
Reviews and improves the final report.

## 🔄 Workflow

Research → Analyze → Write → Review

## 🛠️ Technologies

- Python
- CrewAI
- Streamlit
- Groq
- LiteLLM
- python-dotenv
